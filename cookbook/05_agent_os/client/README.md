# Client Cookbook

Examples for `client` in EgptOS.

## Files
- `01_basic_client.py` — Basic EgptOSClient Example.
- `02_run_agents.py` — Running Agents with EgptOSClient.
- `03_memory_operations.py` — Memory Operations with EgptOSClient.
- `04_session_management.py` — Session Management with EgptOSClient.
- `05_knowledge_search.py` — Knowledge Search with EgptOSClient.
- `06_run_teams.py` — Running Teams with EgptOSClient.
- `07_run_workflows.py` — Running Workflows with EgptOSClient.
- `08_run_evals.py` — Running Evaluations with EgptOSClient.
- `09_upload_content.py` — Uploading Content to Knowledge Base with EgptOSClient.
- `server.py` — EgptOS Server for Cookbook Client Examples.

## Prerequisites
- Load environment variables with `direnv allow` (requires `.envrc`).
- Run examples with `.venvs/demo/bin/python <path-to-file>.py`.
- Some examples require local services (for example Postgres, Redis, Slack, or MCP servers).
